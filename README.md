# ProjectWEB — Σύστημα Διαχείρισης Διπλωματικών Εργασιών

Διαδικτυακή εφαρμογή για τη διαχείριση του κύκλου ζωής μιας διπλωματικής εργασίας σε πανεπιστημιακό τμήμα: από την ανάρτηση του θέματος και την ανάθεση, μέχρι τη συγκρότηση τριμελούς επιτροπής, τον προγραμματισμό της εξέτασης και την τελική βαθμολόγηση.

Αναπτύχθηκε στο πλαίσιο του μαθήματος Τεχνολογίες Διαδικτύου, Τμήμα Μηχανικών Η/Υ & Πληροφορικής, Πανεπιστήμιο Πατρών.

---

## Ρόλοι χρηστών

Η εφαρμογή υποστηρίζει τρεις ρόλους, καθένας με δική του αρχική σελίδα και δικαιώματα.

| Ρόλος | Αρχείο | Τι κάνει |
|---|---|---|
| **Φοιτητής** | `backend/homepage_f.php` | Βλέπει τα διαθέσιμα θέματα, παρακολουθεί την πορεία της διπλωματικής του, ανεβάζει πρόχειρο και συνδέσμους, βλέπει την ημερομηνία εξέτασης |
| **Διδάσκων** | `backend/homepage_d.php` | Αναρτά και διαχειρίζεται θέματα, αναθέτει σε φοιτητές, στέλνει και δέχεται προσκλήσεις για τριμελή επιτροπή, κρατά σημειώσεις, καταχωρεί βαθμούς |
| **Γραμματεία** | `backend/homepage_g.php` | Εποπτεύει το σύνολο των διπλωματικών, καταχωρεί αριθμούς ανάθεσης και ακύρωσης, ολοκληρώνει τη διαδικασία |

Η είσοδος γίνεται από το `backend/index.php`, το οποίο αναγνωρίζει αυτόματα τον ρόλο με βάση τον πίνακα στον οποίο βρίσκεται ο χρήστης και ανακατευθύνει στην αντίστοιχη σελίδα.

## Καταστάσεις διπλωματικής

Κάθε διπλωματική περνά από τέσσερις καταστάσεις, που ορίζονται ως `ENUM` στη βάση:

```
ΥΠΟ ΑΝΑΘΕΣΗ  →  ΕΝΕΡΓΗ  →  ΥΠΟ ΕΞΕΤΑΣΗ  →  (ολοκλήρωση ή ΑΚΥΡΩΜΕΝΗ)
```

Οι ολοκληρωμένες μεταφέρονται στον πίνακα `diplwmatiki_FINISHED`, όπου καταγράφεται ο τελικός βαθμός, το πρακτικό και η ημερομηνία λήξης.

## Δημόσιο API — ανακοινώσεις παρουσιάσεων

Το `backend/index.php` εκθέτει ένα δημόσιο endpoint, προσβάσιμο χωρίς αυθεντικοποίηση, που επιστρέφει τις προγραμματισμένες παρουσιάσεις σε **JSON ή XML**. Προορίζεται για ενσωμάτωση σε ιστοσελίδα τμήματος ή σε τροφοδότη ανακοινώσεων.

```
GET backend/index.php?public_feed=presentations
                      &from=YYYY-MM-DD
                      &to=YYYY-MM-DD
                      &format=json|xml
```

| Παράμετρος | Προεπιλογή | Περιγραφή |
|---|---|---|
| `from` | σήμερα | Αρχή του χρονικού παραθύρου |
| `to` | +365 ημέρες | Τέλος του χρονικού παραθύρου |
| `format` | `json` | `json` ή `xml` |

Η απόκριση περιλαμβάνει τίτλο εργασίας, ημερομηνία και ώρα, τρόπο εξέτασης (διά ζώσης ή διαδικτυακά), αίθουσα ή σύνδεσμο, καθώς και τα στοιχεία φοιτητή και επιβλέποντα. Ορίζεται `Cache-Control: public, max-age=300`.

**Παραδείγματα**

```bash
# Προεπιλεγμένο παράθυρο, JSON
curl "http://localhost/webproject/backend/index.php?public_feed=presentations"

# Συγκεκριμένος μήνας σε XML
curl "http://localhost/webproject/backend/index.php?public_feed=presentations&from=2026-06-01&to=2026-06-30&format=xml"
```

Μη έγκυρη ημερομηνία επιστρέφει `{"success": false, "error": "invalid_date"}`. Περισσότερα παραδείγματα στο [`usage_examples.txt`](usage_examples.txt).

## Τεχνολογίες

- **Backend:** PHP με PDO, prepared statements, sessions
- **Βάση δεδομένων:** MySQL — 9 πίνακες με ξένα κλειδιά και `ON DELETE CASCADE`
- **Frontend:** HTML, CSS και JavaScript χωρίς framework, AJAX για ασύγχρονες κλήσεις
- **Γραφήματα:** Chart.js
- **Βοηθητικός διακομιστής:** Node.js με Express για στατικά αρχεία και μεταφορτώσεις μέσω Multer

## Εγκατάσταση και εκτέλεση

**Προαπαιτούμενα:** PHP 7.4+, MySQL 5.7+, Apache ή άλλος διακομιστής με PHP, Node.js 18+ (προαιρετικά).

**1. Βάση δεδομένων**

```bash
mysql -u root -p < SQLcode.txt
```

Το σενάριο δημιουργεί τη βάση `ProjectWeb`, όλους τους πίνακες και δοκιμαστικά δεδομένα.

**2. Ρύθμιση σύνδεσης**

Στο `backend/includes/db_connect.php` συμπλήρωσε τα δικά σου στοιχεία:

```php
$host     = 'localhost';
$dbname   = 'ProjectWeb';
$username = 'ο_χρήστης_σου';
$password = 'ο_κωδικός_σου';
```

**3. Εκτέλεση**

Τοποθέτησε τον φάκελο στη ρίζα του διακομιστή και άνοιξε:

```
http://localhost/webproject/backend/index.php
```

**4. Διακομιστής Node (προαιρετικά)**

```bash
npm install
node server.js      # http://localhost:3000
```

## Γνωστοί περιορισμοί

Το έργο αναπτύχθηκε ως ακαδημαϊκή εργασία και δεν προορίζεται για παραγωγική χρήση. Τα παρακάτω είναι γνωστά και καταγράφονται συνειδητά:

- **Οι κωδικοί αποθηκεύονται και συγκρίνονται σε απλό κείμενο.** Σε πραγματικό σύστημα θα χρησιμοποιούνταν `password_hash()` και `password_verify()`.
- **Δεν υπάρχει προστασία CSRF** στις φόρμες.
- Τα στοιχεία σύνδεσης στη βάση είναι γραμμένα απευθείας στον κώδικα αντί για μεταβλητές περιβάλλοντος.
- Δεν υπάρχει έλεγχος τύπου αρχείου στις μεταφορτώσεις πέρα από το όριο μεγέθους.
- Δεν υπάρχουν αυτοματοποιημένες δοκιμές.

Οι κλήσεις προς τη βάση χρησιμοποιούν **prepared statements** με παραμέτρους, οπότε το σύστημα δεν είναι ευάλωτο σε SQL injection.



Ακαδημαϊκή εργασία. Ελεύθερο για εκπαιδευτική χρήση και αναφορά.
